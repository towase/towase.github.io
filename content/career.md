### サービス：[カミナシ レポート](https://kaminashi.jp/report)（現場特化ノーコードデジタル帳票サービス）

#### 概要
「カミナシ レポート」は、製造工場・ホテル・飲食店などの現場で使用する紙帳票をデジタル化し、Excelへの転記作業の削減、記録漏れの防止、作業時の逸脱検知、作業指示などを通じて現場業務を改善するノーコードサービス。

顧客の現場業務を支えるため、サービスの安定稼働が特に重要であり、電波の届かない環境でも利用できるオフライン対応、多国籍な従業員に向けた多言語対応、現場で使い続けてもらうためのUXが求められる。

ノーコード帳票の柔軟性とオフライン対応を実現するため、UIや状態管理が複雑で、フロントエンドにビジネスロジックが集中するなどの技術的負債を抱えていた。機能開発のスピードが求められる中、既存iOSアプリの保守とWeb版への段階的リプレイスを並行しながら、機能開発・品質改善・開発基盤の整備に取り組んだ。

#### 役割
ソフトウェアエンジニア（2023年10月〜）、リードエンジニア（2025年7月〜、エンジニア5名チーム）

#### 業務内容
- 既存iOSアプリの保守およびWeb版への段階的リプレイスに伴う設計・実装
- 汎用マスタ機能の開発における設計・実装、およびマスタ管理・CSV一括操作機能の開発リード
- スプリントプランニングにおける技術的制約の整理、PMとの優先順位調整
- オンコール対応および運用改善
- フロントエンド経験の少ないメンバー2名へのペアプログラミング・同期レビューによる開発支援
- CI、テスト方針、依存関係管理などの開発基盤改善

#### 主な取り組み・成果

##### 1. 汎用マスタ機能の開発リード

- **顧客ユースケースを踏まえた機能開発**：PMから共有された顧客の業務課題や利用シーンを踏まえ、汎用性を広げすぎることによる利用方法の複雑化を考慮。初期段階では用途を絞り、顧客フィードバックをもとに段階的に改善する方針のもと開発に取り組んだ
- **帳票連携機能の開発**：前任リードが主導した初期設計を支援し、チームメンバーの開発もリード。マスタと帳票のデータ整合性、マスタ更新時の既存帳票への影響、保存済み帳票を再開する際のデータの扱いなど、複雑な仕様に対応
- **マスタ管理・CSV一括操作機能の設計リード**：前任リードの離脱後、詳細設計・実装をリード。最大100万レコードの追加・更新・削除を想定し、長時間の処理にも対応できる非同期CSV一括操作機能を設計・開発
- **技術選定と運用設計**：同時実行制御などの実装方式を比較・検証。実際の利用規模や将来の機能拡張を踏まえ、開発速度・運用コスト・運用の複雑性を考慮してAWS Batchを採用。DB負荷テストに基づくソフトリミットとアラートを整備し、ダウンタイムを発生させずに本番運用へ移行

##### 2. フロントエンドの技術的負債解消と品質改善

- **状態管理の改善**：ReduxからTanStack Queryへの部分的な移行により、不要なグローバル状態管理を削減。状態のリセット漏れに起因する不具合を解消し、関連ロジックのコロケーションによって可読性・保守性を改善
- **オフライン環境での不具合解消**：iOS Safariで発生していた不具合について、IndexedDBへの不正データ保存を原因として特定。データマイグレーションを含む修正により、複数顧客で継続していた不具合を解消
- **依存技術の更新**：Expoのメジャーアップデートおよびフォークライブラリの修正を実施し、アプリの保守性を維持

##### 3. 品質・開発効率・運用の持続可能性向上

- **品質基準の標準化**：テスト方針をADRとして明文化し、チーム内の判断基準を整理
- **オンコール対応の属人化軽減**：不具合対応の手順や知見をドキュメントとして体系化し、チームの一次参照資料として定着
- **依存関係管理の自動化**：Dependabot Auto MergeのためのGitHub Appと設定ドキュメントを整備し、社内全リポジトリへ展開
- **開発環境の改善**：LocalStackの導入により、開発時の実AWS S3へのアクセスを不要化し、開発・テストの容易性を改善
- **セキュリティ改善**：セキュリティヘッダーの設定によるアプリケーションの安全性向上

##### 4. チーム開発・AI活用の推進

- **メンバーの開発支援**：フロントエンド経験の少ないメンバー2名に対し、ペアプログラミングや同期レビューを通じて開発を支援
- **AIによる開発品質の改善**：AGENTS.mdを整備して開発上の暗黙知を明文化し、同種のコードレビュー指摘の再発を抑制
- **AI活用の習慣化**：チーム内のAI活用ミーティングを主導し、活用方法の試行・振り返りを継続する習慣を定着

##### 5. 技術発信・採用広報への貢献

- 技術ブログを執筆し、はてなブックマーク60件以上を獲得

#### 技術スタック
Go / Echo / React / Expo / React Router / Redux・Zustand・TanStack Query / IndexedDB / AWS / GitHub Actions / GitHub Copilot / Claude Code
